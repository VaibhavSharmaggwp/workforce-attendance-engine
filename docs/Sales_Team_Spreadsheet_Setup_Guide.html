Why this setup? As a sales rep, your daily focus is cold-calling, client demos, and updating your leads sheet. This setup automatically credits your attendance based on your active spreadsheet work, so you never have to worry about keeping the attendance browser tab open!

1. If You Use Google Sheets (Recommended)

Follow these 4 simple steps to connect your sales sheet in under 60 seconds:

  1. Open your sales leads sheet in Google Chrome.
  2. In the top menu bar, click Extensions ➔ Apps Script. A new tab will open with a code editor.
  3. Delete any default code in the editor, and paste the script below:
/**
 * Eduqynt Techviista - Sales Spreadsheet Activity Tracker
 * Automatically verifies active sales work for attendance credit.
 */
var ATTENDANCE_API_URL = "http://localhost:8080/api/v1/activity/pulse";

function onEdit(e) {
  try {
    var userEmail = Session.getActiveUser().getEmail();
    var spreadsheet = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = e ? e.range.getSheet() : spreadsheet.getActiveSheet();
    var range = e ? e.range.getA1Notation() : "A1";

    var payload = {
      employeeEmail: userEmail,
      workbookName: spreadsheet.getName(),
      sheetName: sheet.getName(),
      cellRange: range,
      activityType: "CELL_EDIT",
      details: "Cell update in " + sheet.getName() + "!" + range,
      loggedAt: new Date().toISOString()
    };

    var options = {
      method: "post",
      contentType: "application/json",
      payload: JSON.stringify(payload),
      muteHttpExceptions: true
    };

    UrlFetchApp.fetch(ATTENDANCE_API_URL, options);
  } catch (err) {
    Logger.log("Attendance pulse error: " + err);
  }
}

function testConnection() {
  onEdit(null);
  Logger.log("Test pulse sent successfully!");
}
  1. Click the Save disk icon (or press Ctrl + S).
  2. Done! Every lead entered or cell edited will now automatically register on your daily attendance score.

2. If You Use Desktop Microsoft Excel (.xlsx on PC)

If you work offline in Microsoft Excel installed on Windows:

  1. Open your sales spreadsheet in Microsoft Excel.
  2. Press the keyboard shortcut ALT + F11 to open the VBA Code Editor.
  3. On the left pane under Project - VBAProject, double-click on ThisWorkbook.
  4. Paste this code into the white code box:
Private Sub Workbook_SheetChange(ByVal Sh As Object, ByVal Target As Range)
    On Error Resume Next
    
    Dim http As Object
    Set http = CreateObject("MSXML2.ServerXMLHTTP.6.0")
    
    Dim url As String
    url = "http://localhost:8080/api/v1/activity/pulse"
    
    Dim jsonPayload As String
    jsonPayload = "{""employeeEmail"":""" & Application.UserName & "@techviista.net""," & _
                  """workbookName"":""" & ThisWorkbook.Name & """," & _
                  """sheetName"":""" & Sh.Name & """," & _
                  """cellRange"":""" & Target.Address & """," & _
                  """activityType"":""CELL_EDIT""}"
                  
    http.Open "POST", url, True
    http.setRequestHeader "Content-Type", "application/json"
    http.send jsonPayload
End Sub
  1. Click File ➔ Save As and change the file type to: Excel Macro-Enabled Workbook (*.xlsm).
  2. Done! Whenever you work inside this file, Excel silently sends your proof-of-work pulses to the portal.

4. Privacy & Frequently Asked Questions

Does the system spy on my customer data, phone numbers, or notes?
No. The script never reads or transmits what you type. It only sends a pulse saying: "Employee edited cell B14 at 10:24 AM". Your client information remains 100% private.
What if I am on a customer call for 30 minutes without typing?
The system groups your activity into 10-minute active windows. If you make even 1 note during or after your call, the full block is counted as active productive time.
How do I verify that my work is showing up?
Open the Attendance Portal at any time. Look at the "Sales Spreadsheet Activity" card on your dashboard. It displays your live verified edits and active hours!
